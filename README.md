# Persoonlijke Website - Habibullah 

Een moderne persoonlijke website gebouwd met **HTML**, **CSS** en **JavaScript**.

## Inhoud

- **Home** - Hero sectie met animaties en typewritereffect
- **Over Mij** - Persoonlijke introductie en basisinformatie
- **Vaardigheden** - Skills met geanimeerde progressiebalken
- **Lifestyle** - Hoe ik leef en studeer
- **Hobbies** - Mijn vrijetijdsactiviteiten
- **Contact** - Contactformulier en contactgegevens
- **CV** - Opleiding, ervaring en certificaten

## Features

- Volledig responsive design (mobiel, tablet, desktop)
- Geanimeerde navbar met mobiel menu
- Typewritereffect in de hero sectie
- Scroll-gebaseerde animaties (Intersection Observer)
- Achtergronddeeltjes (particles) in hero
- Geanimeerde tellers voor statistieken
- Floating skill bars
- Dark theme met gradient accenten
- Back-to-top knop
- Interactief contactformulier

## Structuur

```
├── index.html     # Hoofdmap #dit is aangepast
├── style.css      # Styling en animaties
├── script.js      # Interactiviteit
└── README.md      # Deze documentatie
```

## Gebruik

Open het bestand `index.html` in een webbrowser:

```
index.html
```

Of gebruik een lokale server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

Daarna open je `http://localhost:8000` in je browser.

## Aanpassen

Persoonlijke gegevens wijzigen:

1. **Naam en teksten**: Bewerken `index.html`
2. **Kleuren en styling**: Pas CSS-variabelen aan in `style.css` (bovenaan het bestand)
3. **Interacties**: Pas JavaScript aan in `script.js`
